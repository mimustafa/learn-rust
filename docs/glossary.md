# Glossary

| Term | Meaning |
|---|---|
| Borrow | Use a value through a reference without taking ownership |
| Crate | A Rust compilation unit; library or binary |
| Edition | A curated set of language changes selected per crate |
| Future | A value representing work that can make progress when polled |
| Lifetime | A relationship describing how long references remain valid |
| Move | Transfer ownership; the source binding can no longer be used |
| Newtype | A one-field wrapper used to give a value a distinct type/API |
| Ownership | The rule that each value has one owning binding at a time |
| `Send` | A type may be transferred safely between threads |
| `Sync` | Shared references to a type may be sent between threads |
| Trait | A named set of behavior that types can implement |
| Zero-cost abstraction | An abstraction that need not add runtime cost beyond its equivalent lower-level code |
